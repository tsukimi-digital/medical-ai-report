# Sonara — Medical AI Report

Aplikacja wspomagająca pracę radiologa i lekarza przez automatyzację tworzenia raportów medycznych z użyciem AI.

Analiza obrazów USG (Claude Vision) + transkrypcja głosu (Whisper) → strukturyzowany raport do weryfikacji i zatwierdzenia przez specjalistę.

**Stack:** Next.js 14, TypeScript, Tailwind CSS, Claude Opus 4.8, OpenAI Whisper  
**Deployment:** Vercel  
**Status:** POC / Demo
